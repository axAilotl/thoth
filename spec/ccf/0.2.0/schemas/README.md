# CCF 0.2.0 Working Draft schemas

These schemas cover layered conformance declarations, new registries, CCF
Capsule manifests, and uplift/downgrade receipts. They reference the frozen
0.1.2 common definitions and submission schemas rather than copying or
renumbering the portable object algebra.

`catalog.json` is generated by `tools/build-catalog.mjs`. The draft semantic
catalog pins the exact 0.1.2 semantic-catalog root and declares
`ccf/0.1.2` as its portable object format.
